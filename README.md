🧩 Python Mini Projects Collection

This repository contains a collection of small yet functional Python projects built to explore different programming concepts, logic structures, and user interactions. Each script focuses on a specific problem or feature — ranging from games to utility tools — demonstrating both beginner-friendly and advanced Python implementations.

🗂️ Included Projects

🎰 Betting Game – Simple betting logic using randomization and loops.

🎲 Number Guessing Game – Classic guessing game with basic input validation.

🎮 Number Guessing Game (Advanced) – Enhanced version with scoring and attempt limits.

💸 Currency Converter – Converts currency values using pre-defined or fetched rates.

🧮 Calculator – Basic arithmetic calculator implemented with Python logic and functions.

🔐 Password Generator – Generates strong random passwords.

🔑 Password Generator (Advanced) – Adds customization for password length and complexity.

🌦️ Weather App – Fetches and displays real-time weather data (API-based or simulated).

📉 Signal Filtering – Demonstrates basic digital signal processing using filtering techniques.

🧠 Purpose

This collection serves as a learning playground to practise Python fundamentals, including:
1.Loops and conditionals
2.Functions and modularity
3.Randomization and user input

File handling and APIs

Data processing and basic algorithms
